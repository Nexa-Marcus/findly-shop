# FINDLY – Affiliate-Shop Starter (Demo)

Eine responsive Demo-Website in HTML, CSS und JavaScript. Keine Installation erforderlich.

## Öffnen
1. ZIP-Datei entpacken.
2. `index.html` doppelklicken oder im Browser öffnen.
3. Zum Bearbeiten den Ordner in VS Code öffnen.

## Produkte ändern
Öffne `script.js`. Im Array `products` kannst du Name, Kategorie, Beschreibung und Emoji ändern. `affiliateUrl` ist bewusst leer; erst nach Partnerfreigabe einen gültigen, autorisierten Link eintragen. Solange er fehlt, ist die Schaltfläche deaktiviert.

## Vor Veröffentlichung
- Temu-Partnerprogramm beantragen und klären, ob ein eigener Affiliate-Katalog/Website als Werbekanal akzeptiert wird, und welche Links sowie Medien erlaubt sind.
- Eigene oder autorisiert nutzbare Produktbilder und korrekte Produktinformationen verwenden. Demo-Emojis ersetzen.
- Impressum und Datenschutz individuell ergänzen; `rechtliches.html` enthält nur Platzhalter.
- Gewerbliche/steuerliche Pflichten in Deutschland prüfen; Werbe- und Affiliate-Kennzeichnung beibehalten.
- Hosting, Domain, technische und rechtliche Prüfung erledigen.
- Kein Checkout auf dieser Website. Bestellungen laufen beim externen Anbieter.

## Dateien
- index.html – Hauptseite
- style.css – Gestaltung
- script.js – Produktkatalog und Filter
- rechtliches.html – Rechtstext-Platzhalter (NICHT veröffentlichungsfertig)
